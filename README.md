# 🕷️ Portfólio Spider-Verse

Projeto de portfólio inspirado no universo Spider-Verse, desenvolvido com HTML, CSS e JavaScript.

## 🚀 Sobre o projeto

Este projeto foi criado com o objetivo de praticar e demonstrar habilidades básicas em desenvolvimento web, incluindo estruturação de páginas, estilização e interatividade.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎨 Funcionalidades

- Layout temático inspirado no Spider-Verse
- Interface visual moderna
- Estrutura organizada de arquivos
- Interações básicas com JavaScript

## 📌 Objetivo

Desenvolver um projeto inicial para consolidar conhecimentos fundamentais em front-end e servir como base para projetos mais avançados.
